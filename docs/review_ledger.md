# Review ledger

**Unresolved findings only.** One row per finding:
`ID | agent | severity | status | anchor | finding | resolution`.

Status is **OPEN** or **DEFERRED** (out of scope for the current gate, with a
reason and the gate it belongs to). There is no resolved state: a finding that is
fixed is DELETED. Git is the audit trail — `git log -S '<id>' -p -- docs/review_ledger.md`.

This file says what still needs doing. It is not a record of how anything was
done; that belongs in `docs/design_spec.md` if it matters at all, and nowhere if
it does not.

**Write in-cell pipes as `&#124;`.** A raw `|` inside a cell truncates the row at
that point, and the text after it is gone from the file. Sixteen rows were
silently cut this way — 10.5 KB, mostly resolution cells, i.e. exactly the
implementer instructions a row exists to carry. Recovered from git history
2026-08-12.

**Where deleted rows' couplings went.** Many live rows read "fix WITH AC-54" or
cite AC-176. Both are fixed and their rows deleted; what they were coupling to is
now DECLARED IN CODE, and that declaration is the thing to fix consistently with:

- **AC-54 / AC-66 / AC-56 / AC-184** — the backend's absorption convention, its
  realized record support, and the air-absorption fraction are declared in
  `configs/simulators/gsound_sir.yaml` and applied in
  `src/amcd/simulators/gsound_sir.py`. Cluster C6's remaining members close
  against that declaration.
- **AC-176** — the ISO 3382-1 SNR admissibility bound is live at
  `src/amcd/evaluation/room_acoustic.py` `_decay_times_from_energy`, keyed by
  `metric_min_decay_range_db`.
