# Review ledger

**Unresolved findings only.** One row per finding:
`ID | agent | severity | status | anchor | finding | resolution`.

Status is **OPEN** or **DEFERRED** (out of scope for the current gate, with a
reason and the gate it belongs to). There is no resolved state: a finding that is
fixed is DELETED. Git is the audit trail — `git log -S '<id>' -p -- docs/review_ledger.md`.

This file exists so unsolved work survives a lost context window. **That is its
only job.** It is not a record of process: no cycle narration, no pass counts, no
rows about the ledger itself or the machinery around it. A row that changes
neither what the code does nor what a reported number means does not belong here.

**Nothing is added without the user's approval.** A finding that cannot be fixed
is raised as a research-limitation decision, so the project can move past it —
never filed for a later session to inherit and ignore.

**A cited row id that is not in this file is a finding that was fixed and
deleted.** It is kept where it names a defect SHAPE a reader already knows
("the AC-24 divergence shape" = two declarations of one fact drifting apart).
`git log -S '<id>' -p` recovers it; nothing here depends on looking it up.

**Write in-cell pipes as `&#124;`.** A raw `|` inside a cell truncates the row at
that point, and the text after it is gone from the file.
